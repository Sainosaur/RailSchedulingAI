FIX 2 — ACCEL_NOT_ZERO_VIOLATION logic is too broad.
 
Current code:
    if (u < 0.1 and abs(proposed_a) > 0.01) or \
       (abs(u - seg.limit_ms) < 0.01 and proposed_a > 0.01):
 
Change to:
    if (u < 0.1 and proposed_a < -0.01) or \
       (abs(u - seg.limit_ms) < 0.01 and proposed_a > 0.01):
 
Reason:
- Stationary check now only flags NEGATIVE acceleration (which would reverse the
  train and cause negative speed). Positive acceleration when stationary is not
  flagged here — if the train creeps into the next zone, the spatial violation fires.
- Speed limit check is unchanged — only flags positive acceleration at the limit.

FIX 4 — Speed compliance uses raw distance instead of signal aspect.
 
Under the zone-based design the AI reasons via signal aspects, not raw distances.
Remove d_to_obs and optimal_braking_distance from the speed compliance logic.
 
Replace the entire speed compliance block (component 2, labelled "Speed Compliance
Reward") with:
 
    # 2. Speed Compliance Reward
    # Regime is determined by the more restrictive of train_aspect and station_aspect.
    # Green  (3): clear road ahead — reward staying near the speed limit.
    # DY/Yellow (2/1): approaching obstacle — reward service braking at 0.5 m/s/s.
    # Red    (0): must stop — reward braking or being stopped.
    effective_aspect = min(train_aspect, station_aspect)
 
    if effective_aspect == 3:
        out.r_speed = -abs(u - state.speed_limit)
    elif effective_aspect in (1, 2):
        if -0.55 <= a <= -0.45:
            out.r_speed = 5.0
        elif -1.0 < a < -0.55:
            out.r_speed = -2.0   # Harder than service braking but not emergency
        elif a <= -1.0:
            out.r_speed = 0.0    # Emergency braking is never penalised
    elif effective_aspect == 0:
        if u < 0.1:
            out.r_speed = 0.0    # Correctly stopped
        elif a <= -0.45:
            out.r_speed = 2.0    # Braking correctly toward stop
        else:
            out.r_speed = -5.0   # Moving at Red without adequate braking
 
Remove from the top of compute_reward (no longer used):
    optimal_braking_distance = info.get("optimal_braking_distance", 0.0)
 
Remove any remaining references to d_to_obs in the speed compliance block.
