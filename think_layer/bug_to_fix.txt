THINK LAYER — STATUS & KNOWN ISSUES
=====================================

OBJECTIVES — WHAT'S MET AND WHAT ISN'T
-----------------------------------------

Jerk minimisation (smooth driving, no abrupt changes)
  STATUS: Met — the reward penalises sudden acceleration swings.
  MINOR FIX NEEDED: One variable has the wrong data type internally
  (stored as a whole number, should be a decimal). Low priority, won't
  cause crashes but should be tidied.

Maximum velocity (train runs near the speed limit when safe)
  STATUS: Partially met — the agent is penalised for going TOO FAST,
  but there is currently ZERO reward for going fast enough. This means
  the agent has no reason to maintain speed and may learn to crawl.
  FIX: Turn on the "underspeed" reward (currently switched off).

Energy efficiency (avoid unnecessary throttle use)
  STATUS: Met — coasting and braking are free; traction burns reward.
  No changes needed.

Punctuality (arrive at stations on time)
  STATUS: NOT MET — the code for this exists but is completely inactive.
  The environment never feeds it the timetable data it needs, so the
  penalty never fires. Either wire up a timetable or remove it for now.


BUGS TO FIX
-----------

1. Seed is set twice during startup and the second one silently wipes
   the first. Harmless but messy — one line to delete.

2. The evaluation environment shares its normalisation settings with the
   training environment instead of taking its own separate copy. As
   training progresses the evaluation numbers drift incorrectly.
   Easy fix.

3. The evaluation CSV logs normalised (scaled) position and speed values
   instead of real metres and m/s. Any plots from this file will show
   the wrong numbers.

4. The safety override penalty (-500 points) is so large it drowns
   everything else out. The agent will obsess over never triggering the
   safety system rather than learning to drive well. Needs to come down
   to roughly -10 to -25.

5. The headway warning logic has a gap: the "approaching too close"
   warning signal disappears completely at the exact moment the agent
   is closest to the lead train. The agent loses the signal it needs
   most. One-line logic fix.
